# Many Stars Server Code Repository - 繁星計畫伺服器端程式碼倉庫
## 壹、簡介
本倉庫為大型 Minecraft 伺服器企劃「繁星計畫」的官方伺服器端程式碼倉庫，用於存放伺服器端程式碼及其他資源。

## 贰、倉庫結構介紹
- **docker**
  - 介紹：Docker 映像檔分支，存放繁星計畫專用 Docker 映像檔
- **starfield**
  - 介紹：繁星計畫下屬生存向群組伺服器《星空神域》程式碼存放目錄
- **promisedworld**
  - 介紹：繁星計畫下屬生電向群組伺服器《應許之世》程式碼存放目錄
- **blueplatform**
  - 介紹：繁星計畫下屬 RPG 劇情向群組伺服器《蔚藍站台》程式碼存放目錄
