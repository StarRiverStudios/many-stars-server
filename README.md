# Many Stars Server Code Repository - 繁星计划服务端代码仓库
## 一、简介
本仓库为大型Minecraft服务器企划“繁星计划”的官方服务端代码仓库，用于存放服务端代码及其他资源。

## 二、仓库结构介绍
- **docker**
  - 介绍：Docker镜像分支，存放繁星计划专用Docker镜像文件
- **starfield**
  - 介绍：繁星计划下属生存向群组服务器《星空神域》代码存放目录
- **promisedworld**
  - 介绍：繁星计划下属生电向群组服务器《应许之世》代码存放目录
- **blueplatform**
  - 介绍：繁星计划下属RPG剧情向群组服务器《蔚蓝站台》代码存放目录
