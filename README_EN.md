# Many Stars Server Code Repository
## I. Introduction
This repository is the official server-side code repository of the large-scale Minecraft server project "Project Many Stars". It stores server-side code and other resources.

## II. Repository Structure
- **docker**
  - Description: Docker image branch, storing Docker image files dedicated to Project Many Stars.
- **starfield**
  - Description: Directory that stores the code of *Starfield*, a survival-oriented server network under Project Many Stars.
- **promisedworld**
  - Description: Directory that stores the code of *Promised World*, a technical Minecraft (redstone & farming) server network under Project Many Stars.
- **blueplatform**
  - Description: Directory that stores the code of *Blue Platform*, an RPG story-driven server network under Project Many Stars.
